# agencia_de_viajes1
Descripción del Proyecto: Sistema Integrado de Agencia de Viajes y Turismo  Este script en Python es un sistema interactivo de consola diseñado para gestionar operaciones de una agencia de viajes, ofreciendo flujos de trabajo diferenciados según el perfil del usuario (Empleado/Agencia o Cliente).  Características Principales  Gestión de Perfiles y Autenticación:  Modo Empleado: Requiere validación de credenciales (usuario y contraseña) para acceder a funciones administrativas y operativas.  Modo Cliente: Ofrece acceso directo a consultas de ofertas, agendamiento e interacción sin requerir inicio de sesión.  Módulos Operativos (Empleado):  Registro en Hoteles: Captura datos del cliente, establecimiento, noches de estancia y tipo de habitación.  Vuelos y Grupos Familiares: Registra la información del titular, destino, número de integrantes y realiza la suma del peso total del equipaje (mano y bodega).  Desglose de Facturación: Calcula y desglose de forma automática el monto total ingresado en denominaciones de billetes ($1000, $100) y monedas ($10, $1).  Módulos de Servicios (Cliente):  Catálogo de Tarifas: Consulta de precios de vuelos, opciones de hospedaje y paquetes turísticos completos.  Agendamiento de Viajes: Formulario para la solicitud de reservas especificando destino, fecha y cantidad de pasajeros.  Sistema de Reseñas y Cupones: Recibe retroalimentación del servicio y otorga automáticamente un cupón de descuento proporcional a la longitud del texto ingresado.  Tecnologías Utilizadas  Lenguaje: Python 3  Conceptos aplicados: Funciones modulares, control de flujo (while, if-elif-else), manejo de cadenas, operadores aritméticos/módulo (//, %) e interacciones por consola (input/print).
